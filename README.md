# AZoom – Electric Car Rental

ISIT207 Assignment 2 A. AZoom A car rental website built with HTML, CSS and JavaScript.

## Files

```
index.html     main page
css/           styles
js/            data.js (cars, prices, locations) and app.js (site logic)
img/           logo, hero image and car photos
```

## How to run

Open the folder in VS Code and use the **Live Server** extension
(right-click `index.html` → Open with Live Server).

Don't double-click `index.html`, because the map won't load that way.

## Notes

- There's no back end. Data is saved in the browser (localStorage).
- The map uses Leaflet and OpenStreetMap. No API key is needed.
